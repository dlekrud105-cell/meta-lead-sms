# Your Painter — 브랜드 / 차량 랩핑 에셋

## 파일

| 파일 | 용도 |
|---|---|
| `logo-original.png` | 원본 로고 (핑크 + 블랙 스크립트). 밝은 배경 전용. |
| `logo-reverse-on-dark.png` | 반전 버전 (핑크 + **화이트** 스크립트). 검정 차체·어두운 배경 전용. |
| `logo-mono-white.png` | 단색 화이트. 소형 적용 / 1도 인쇄용. |
| `van-wrap-spec.html` | 스타리아 하이브리드 랩핑 시공 도면 (측면·후면·전면 + 컷 리스트 + 자재 사양). |

## 브랜드 컬러

- Brand Pink — `#F86B91` (RGB 248 · 107 · 145)
- Script White — `#FFFFFF`

## 반전 로고를 따로 두는 이유

원본 로고의 스크립트("Your")가 검정입니다. 검정 차체나 어두운 배경에 원본을 그대로 쓰면
스크립트가 배경에 묻혀 사라지고 `PAINTER` 핑크 블록만 남습니다.
어두운 배경에서는 반드시 `logo-reverse-on-dark.png`를 쓰세요.

## 랩핑 도면

`van-wrap-spec.html`을 브라우저로 열면 됩니다. 축척 1:50, 전 치수 mm.
차량 기준값: 전장 5255 · 전폭 1995 · 전고 1990 · 축거 3273 (롱바디).
시공 전 실차 실측으로 재확인 필요.
