# Your Painter — 브랜드 / 차량 랩핑 에셋

## 파일

| 파일 | 용도 |
|---|---|
| `logo-original.png` | 원본 로고 (핑크 + 블랙 스크립트). 밝은 배경 전용. |
| `logo-reverse-on-dark.png` | 반전 버전 (핑크 + **화이트** 스크립트). 검정 차체·어두운 배경 전용. |
| `logo-mono-white.png` | 단색 화이트. 소형 적용 / 1도 인쇄용. |
| `van-wrap-spec.html` | 스타리아 하이브리드 랩핑 시공 도면 (측면·후면·전면 + 컷 리스트 + 자재 사양). |
| `mockup-side.jpg` | 실차 사진 합성 목업 (측면). |
| `mockup-side-detail.jpg` | 위 목업의 도어 부분 확대. |
| `wrap_decal.py` | 사진에 로고를 원근 변환해 합성하는 스크립트. |

## 브랜드 컬러

- Brand Pink — `#F86B91` (RGB 248 · 107 · 145)
- Script White — `#FFFFFF`

## 반전 로고를 따로 두는 이유

원본 로고의 스크립트("Your")가 검정입니다. 검정 차체나 어두운 배경에 원본을 그대로 쓰면
스크립트가 배경에 묻혀 사라지고 `PAINTER` 핑크 블록만 남습니다.
어두운 배경에서는 반드시 `logo-reverse-on-dark.png`를 쓰세요.

## 랩핑 도면

`van-wrap-spec.html`을 브라우저로 열면 됩니다. 축척 1:50, 전 치수 mm.
차량 기준값: 전장 5255 · 전폭 1995 · 전고 1990 · 축거 3273 (롱바디).
시공 전 실차 실측으로 재확인 필요.

## 목업 다시 뽑기

`wrap_decal.py`는 차량 측면 평면의 mm 좌표를 사진 픽셀로 보내는 호모그래피를 만들고,
로고를 그 평면에 역워핑한 뒤 해당 패널의 명암·반사를 입혀 비닐처럼 합성합니다.
새 사진으로 다시 뽑으려면 대응점 4쌍(슬라이딩 도어 앞/뒤 절개선 × 벨트라인/하단)만 바꾸면 됩니다.

현재 목업의 바탕은 현대 카탈로그 사진입니다 — 이 회사 차량이 아니고, 대외 홍보에는 쓸 수 없습니다.
실차 사진으로 교체 필요.

## 실차에서 확인된 사항

스타리아의 슬라이딩 도어 손잡이는 도어 **앞쪽**에 있습니다 (앞도어 손잡이와 나란히).
창문 아래 평평한 면 870mm 중 위쪽 약 260mm를 손잡이가 차지하므로,
로고는 손잡이 아래에 놓이고 가로 850mm가 실질적인 최대치입니다.
